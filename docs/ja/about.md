# Papexについて

Papexは、学術文献を管理し発見するための**オープンソースで独立した**プラットフォームです。私たちの目標は、研究者に開かれた、透明性のある、自分でホストできるインフラを提供することです。

## 私たちの使命

Papexは、学術文献インフラへの参入障壁を下げます。投稿やバージョン管理から全文検索、オープンAPIに至るまで、すべてを自由に導入し拡張できます。私たちは、ベンダーロックインよりもオープンな標準とコミュニティとの協働を重視します。

## 主な機能

- **投稿とバージョン管理**: 要約・著者・PDFが永続的にアーカイブされた複数バージョンの論文。PDFの一括解析により、アップロード時に本文テキストと参考文献を抽出します。取り下げには理由が記録されます。
- **全文検索と高度な検索**: `tsvector` + `pg_trgm` による多言語（CJK／英語）検索、高度なブール構文（`ti/abs/au/cat/id` によるフィールド指定、AND/OR/NOT、括弧）に対応。カテゴリ・著者・日付範囲の絞り込みと被引用順の並び替えが可能です。
- **カテゴリとタグ**: クロス掲載に対応した分野カテゴリのツリーに加え、ユーザー作成タグ、自動タグ付け、ホームの人気タグクラウドを備えています。
- **著者と所属**: 著者が発表論文と所属機関を一覧できるプロフィール。
- **引用・解析・書き出し**: 引用グラフ（DOI／論文IDの関係）に力指向ビュー、共被引用と共著解析、被引用数、およびGB/T 7714・BibTeX・APAでの書き出し。
- **書誌計量**: 著者ごとの被引用総数、H指数、およびEChartsによる共著ネットワーク。
- **コメントと議論**: 各論文にスレッド形式の返信。
- **購読・通知・RSS／メール**: カテゴリ・著者・論文をフォロー。未読バッジ付きの統合フィード、任意のResend／SMTPまたはRSS配信。
- **ブックマークとグループ**: ワンクリック保存と名前付きブックマークグループで、後で読むコレクションを整理。
- **メッセージ・チケット・フィードバック**: 組み込みの内部メッセージ、チケットの状態遷移、フィードバックによるコミュニティサポート。
- **共創レビュー（ピアレビュー）**: 割り当て・応答・意見提出・受領までの完全なループを、統合通知付きで提供。
- **権限・ロール・推薦**: ロールごとまたはユーザーごとの制御を持つロールベースのきめ細かなアクセス、モデレーションキュー、および初回投稿時の推薦ゲート。
- **管理解析**: 投稿・カテゴリ・著者・レビューの集計をグラフ付きで表示。
- **オープンAPIとAPIキー**: インタラクティブなドキュメントを備えたOpenAPI 3.1仕様に加え、所有者のRBACを継承するプログラム向けAPIキー。
- **プロフィール・テーマ・i18n**: 個人プロフィールと `/u/[username]` ページ、ライト／ダークテーマ、中国語／英語のインターフェース。
- **ブラウザベースの執筆（Writespace）**: ブラウザ上でのLaTeX執筆・コンパイル・ワンクリック公開。
