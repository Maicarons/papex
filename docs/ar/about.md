# حول Papex

Papex هي منصة **مفتوحة المصدر ومستقلة** لإدارة الأدبيات الأكاديمية واكتشافها. هدفنا هو تزويد الباحثين ببنية تحتية مفتوحة وشفافة وقابلة للاستضافة الذاتية.

## مهمتنا

يخفّض Papex عتبة بنية الأدبيات الأكاديمية: بدءًا من الإرسال وإدارة الإصدارات وصولًا إلى البحث في النص الكامل وواجهات البرمجة المفتوحة، يمكن نشر كل شيء وتوسيعه بحرية. نحن نقدّر المعايير المفتوحة وتعاون المجتمع أكثر من الاحتكار.

## الميزات الأساسية

- **الإرسال وإدارة الإصدارات**: أوراق متعددة الإصدارات مع ملخصات ومؤلفين وملفات PDF محفوظة بشكل دائم؛ ويستخرج تحليل PDF بالجملة النص والمراجع عند الرفع؛ ويمكن السحب مع تسجيل سبب.
- **البحث في النص الكامل والبحث المتقدم**: بحث متعدد اللغات (صيني/إنجليزي) عبر `tsvector` + `pg_trgm`، وبنية منطقية متقدمة (`ti/abs/au/cat/id` لتحديد الحقول، AND/OR/NOT، والأقواس)، مع فلاتر للفئة والمؤلف والنطاق الزمني وترتيب حسب الاقتباس.
- **الفئات والوسوم**: شجرة من فئات الموضوعات مع إدراج متقاطع، إضافة إلى وسوم ينشئها المستخدم وتوسيم تلقائي وسحابة وسوم رائجة في الصفحة الرئيسية.
- **المؤلفون والانتماءات**: ملفات تعريف للمؤلفين تُدرج الأوراق والانتماءات المؤسسية.
- **الاقتباسات والتحليلات والتصدير**: رسم بياني للاقتباس (علاقات DOI / معرّف الورقة) بعرض موجَّه بالقوة، وتحليل الاقتباس المشترك والمؤلفين المشاركين، وأعداد الاقتباس، وتصدير وفق GB/T 7714 · BibTeX · APA.
- **القياس الببليومتري**: إجماليات اقتباس لكل مؤلف، ومؤشر H، وشبكة مؤلفين مشاركين عبر ECharts.
- **التعليقات والنقاش**: ردود متفرعة على كل ورقة.
- **الاشتراكات والتنبيهات وRSS/البريد**: تابع الفئات والمؤلفين والأوراق؛ وتغذية موحدة بشارة غير مقروء مباشرة؛ مع تسليم اختياري عبر Resend/SMTP أو RSS.
- **الإشارات المرجعية والمجموعات**: حفظ بنقرة واحدة إضافة إلى مجموعات إشارات مسمّاة لتنظيم مجموعة قراءة لاحقة.
- **الرسائل والتذاكر والتعليقات**: رسائل داخلية مدمجة وآلة حالة للتذاكر وتعليقات لدعم المجتمع.
- **المراجعة المشتركة (تحكيم الأقران)**: حلقة كاملة من التعيين والرد وتقديم الرأي والإيصال، مع إشعارات موحدة.
- **الصلاحيات والأدوار والتزكية**: وصول دقيق قائم على الأدوار مع تحكم لكل دور أو لكل مستخدم، وقائمة انتظار للإشراف، وبوابة تزكية للإرسال الأول.
- **تحليلات الإدارة**: تجميعات للإرسال والفئات والمؤلفين والمراجعات مع رسوم بيانية.
- **واجهة برمجة تطبيقات مفتوحة ومفاتيح API**: مواصفة OpenAPI 3.1 مع توثيق تفاعلي، إضافة إلى مفاتيح API برمجية ترث نظام RBAC الخاص بصاحبها.
- **الملفات الشخصية والسمات والتعريب**: ملفات شخصية وصفحات `/u/[username]`، وسمات فاتح/داكن، وواجهة صينية/إنجليزية.
- **التأليف عبر المتصفح (Writespace)**: كتابة وتجميع LaTeX عبر المتصفح والنشر بنقرة واحدة.
