    details: 초록과 저자 메타데이터가 유지보수되는 다중 버전 논문.
  - title: 전문 검색
    details: 제목·초록·저자 전반에 걸친 빠른 전문 인덱싱으로, 중국어/영어 혼용도 지원.
  - title: 오픈 API
    details: 통합과 맞춤 도구 제작을 위한 오픈 HTTP API.
  - title: 메시지 및 티켓
    details: 커뮤니티 지원을 위한 내장 메시지·티켓·피드백.
  - title: 공동 리뷰(피어 리뷰)
    details: 배정·수락·의견 제출·접수증으로 이어지는 완결된 리뷰 루프와 통합 알림.
  - title: 권한 및 사용자 관리
    details: 역할 기반의 세밀한 권한 체계로 역할별 또는 사용자별 허용/거부를 지원.
  - title: 온라인 집필
    details: 브라우저에서 papex.json을 시각적으로 편집하고 LaTeX 본문을 작성한 뒤, 소스 패키지를 내보내거나 한 번에 게시.
  - title: 구독 및 알림
    details: 분류·저자·논문을 팔로우하고, 실시간 읽지 않음 배지를 포함한 통합 공지 피드를 받음.
  - title: 북마크
    details: 한 번의 클릭으로 논문을 저장하고, 이름 붙은 그룹으로 정리하며 전용 컬렉션 페이지에서 관리.
  - title: 인용 분석
    details: 힘 기반 인용 그래프, 공인용/인용/2차 참고문헌, 인용 횟수, GB/T 7714 · BibTeX · APA 내보내기.
  - title: 서지계량학
    details: 저자별 인용 합계, H-지수, 공저자 네트워크와 함께 출판 추이 및 키워드 동시출현 분석.
  - title: 태그 및 고급 검색
    details: 사용자가 만든 태그와 키워드 동시출현 그래프, 인기 태그 구름, 그리고 필드/시간 범위/정렬을 고려하는 검색 UI.
  - title: 의미 및 하이브리드 검색
    details: 벡터(pgvector) 임베딩과 전문 랭킹을 융합하여 의미를 인식하는 논문 탐색. 임베딩 백엔드가 설정되지 않으면 자동으로 키워드 검색으로 폴백.
  - title: 외부 메타데이터 가져오기
    details: Crossref, arXiv, Semantic Scholar, OpenCitations에서 한 번에 가져오며, 출처 간 중복 제거와 인용 자동 보완.
