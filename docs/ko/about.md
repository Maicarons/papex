# Papex 소개

Papex는 학술 문헌을 관리하고 발견하기 위한 **오픈소스 독립** 플랫폼입니다. 우리의 목표는 연구자에게 개방적이고 투명하며 직접 호스팅 가능한 인프라를 제공하는 것입니다.

## 우리의 미션

Papex는 학술 문헌 인프라의 진입 장벽을 낮춥니다. 투고와 버전 관리부터 전문 검색과 오픈 API까지, 모든 것을 자유롭게 배포하고 확장할 수 있습니다. 우리는 종속성(lock-in)보다 개방형 표준과 커뮤니티 협업을 중시합니다.

## 주요 기능

- **투고 및 버전 관리**: 초록·저자·PDF가 영구 보관되는 다중 버전 논문; 일괄 PDF 파싱이 업로드 시 본문과 참고문헌을 추출하며, 사유를 기록하며 철회 가능.
- **전문 및 고급 검색**: `tsvector` + `pg_trgm` 다국어(CJK/영어) 검색, 고급 불리언 문법(`ti/abs/au/cat/id` 필드 지정, AND/OR/NOT, 괄호), 분류·저자·날짜 범위 필터와 인용 정렬 지원.
- **분류 및 태그**: 교차 등재가 가능한 주제 분류 트리와 함께, 사용자가 만든 태그, 자동 태깅, 홈페이지 인기 태그 구름.
- **저자 및 소속**: 논문과 소속 기관을 나열하는 저자 프로필.
- **인용·분석 및 내보내기**: DOI / 논문 ID 관계를 보여주는 인용 그래프(힘 기반 시각화), 공인용 및 공저 분석, 인용 횟수, GB/T 7714 · BibTeX · APA 내보내기.
- **서지계량학**: 저자별 인용 합계, H-지수, ECharts 공저자 네트워크.
- **댓글 및 토론**: 모든 논문에 달린 계층형 답글.
- **구독·알림 및 RSS/이메일**: 분류·저자·논문을 팔로우하고, 실시간 읽지 않음 배지를 포함한 통합 피드와 선택적 Resend/SMTP 또는 RSS 전송.
- **북마크 및 그룹**: 한 번의 클릭으로 저장하고 이름 붙은 북마크 그룹으로 나중에 읽을 컬렉션을 정리.
- **메시지·티켓 및 피드백**: 내장 메시지, 티켓 상태 머신, 커뮤니티 지원용 피드백.
- **공동 리뷰(피어 리뷰)**: 배정·응답·의견 제출·접수증으로 이어지는 완결된 루프와 통합 알림.
- **권한·역할 및 추천(endorsement)**: 역할 기반의 세밀한 접근 제어로 역할별 또는 사용자별 통제, 검토 대기열, 첫 투고 추천 게이트.
- **관리자 분석**: 투고·분류·저자·리뷰 집계를 차트로 제공.
- **오픈 API 및 API 키**: 대화형 문서를 갖춘 OpenAPI 3.1 명세와, 소유자의 RBAC를 상속하는 프로그래밍 방식 API 키.
- **프로필·테마 및 i18n**: 개인 프로필과 `/u/[username]` 페이지, 라이트/다크 테마, 중국어/영어 인터페이스.
- **브라우저 기반 집필(Writespace)**: 브라우저에서 LaTeX 작성·컴파일·한 번에 게시.

## 오픈소스

Papex는 [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) 라이선스로 배포되며 상업·비상업 모두 자유롭게 사용할 수 있습니다. 티켓과 피드백을 통해 기여를 환영합니다.
