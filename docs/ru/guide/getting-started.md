# Начало работы

Это руководство поможет запустить Papex локально.

## Требования

- Node.js ≥ 18.18
- PostgreSQL ≥ 16 (рекомендуется Docker)
- npm или pnpm

## 1. Установка зависимостей

```bash
npm install
```

## 2. Подготовка базы данных

Запустите Postgres с поставляемым `docker-compose.yml`:

```bash
docker compose up -d db
```

Скопируйте и заполните файл окружения:

```bash
cp .env.example .env
# Укажите хотя бы DATABASE_URL и AUTH_SECRET
```

## 3. Применение миграций и начальных данных

```bash
npm run db:migrate
npm run db:seed
```

`db:seed` записывает полную таксономию категорий, примеры работ и учётную запись администратора.

## 4. Запуск сервера разработки

```bash
npm run dev
```

Откройте http://localhost:3000.

## Учётные записи по умолчанию

| Роль | Имя пользователя | Пароль |
| --- | --- | --- |
| Админ | `admin` | `admin123456` |
| Автор (пример) | `demo` | `password123` |

> Смените пароли по умолчанию в production и используйте длинный случайный `AUTH_SECRET`.
