    details: 支持多版本论文、摘要与作者信息维护，每次提交进入审核队列。
  - title: 全文检索
    details: 基于全文索引（含中文 trigram）的快速检索，覆盖标题、摘要与作者。
  - title: 开放 API
    details: 提供开放的 HTTP API，便于二次开发与系统集成。
  - title: 站内信与工单
    details: 内置站内信、工单与反馈系统，便于社区协作与支持。
  - title: 同行评审（协审）
    details: 完整的协审闭环——指派、接收确认、提交意见与结果回执，并联动统一通知。
  - title: 权限与用户管理
    details: 基于角色的细粒度权限体系，支持按角色或用户粒度允许 / 禁止各项操作。
  - title: 在线创作
    details: 浏览器内可视化编辑 papex.json、撰写 LaTeX 正文，并直接导出源码包或一键发布。

Papex 是一个开源、独立的学术文献管理与发现平台。你可以自托管部署，也可以在其基础上进行二次开发。
