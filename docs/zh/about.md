# 关于 Papex

Papex 是一个**开源、独立**的学术文献管理与发现平台，目标是为研究者提供开放、透明、可自托管的文献基础设施。

## 我们的使命

Papex 致力于降低学术文献基础设施的门槛：从投稿、版本管理到全文检索与开放 API，一切皆可自由部署与扩展。我们重视开放标准与社区协作，而非锁定。

## 核心特性

- **投稿与版本管理**：多版本论文，摘要、作者与 PDF 永久归档；上传时批量解析 PDF 文本与参考文献；撤稿记录原因。
- **全文与高级检索**：基于 `tsvector` + `pg_trgm` 的中英多语言检索，支持高级布尔语法（`ti/abs/au/cat/id` 字段作用域、AND/OR/NOT、括号），并提供分类、作者、时间范围筛选与按被引排序。
- **分类与标签**：学科分类树支持交叉归属，并提供用户自建标签、投稿自动打标与首页热门标签云。
- **作者与机构**：作者主页汇聚其论文与所属机构。
- **引用图谱、分析与导出**：以 DOI / 文献编号记录引用关系，提供力导视图、共引/同被引与二级引用分析、被引计数，并支持 GB/T 7714 · BibTeX · APA 一键导出。
- **文献计量**：作者页展示被引总数、H 指数与 ECharts 合作网络。
- **评论与讨论**：每篇论文支持楼层式 threaded 回复。
- **订阅、提醒与 RSS/邮件**：关注分类、作者与论文，汇聚成统一提醒流并带实时未读角标；可选 Resend/SMTP 或 RSS 投递。
- **收藏与分组**：一键收藏，并用命名分组管理稍后读清单。
- **站内信、工单与反馈**：内置站内信、工单状态机与反馈，便于社区支持。
- **同行评审（协审）**：完整协审闭环，指派、回应、提交意见与回执，并联动统一通知。
- **权限、角色与背书**：基于角色的细粒度权限，支持按角色或用户粒度控制，含审核队列与首次投稿背书门禁。
- **管理分析**：投稿、分类、作者与审核的聚合统计与图表。
- **开放 API 与 API Key**：提供 OpenAPI 3.1 规范与交互式文档，并支持继承所有者 RBAC 的编程式 API Key。
- **个人主页、主题与国际化**：个人主页与 `/u/[username]` 页，支持明暗主题与中英文界面。
- **浏览器端写作（Writespace）**：浏览器内 LaTeX 编写、编译与一键发布。
